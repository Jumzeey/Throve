Throve — High-Fidelity Master

This is the single growing master file. It currently contains Screens 1–5 (Welcome & accounts). Later batches append Screens 6–34 in place, in this same file, in numerical order.

Visual direction carries over from the earlier hi-fi batches: Classical system, Cormorant Garamond over Lora, warm-gold accent, hairline dividers, matted photography. One correction applies from this batch onward: primary transactional actions are now filled (solid accent, white label) rather than outlined, so the strongest action on each screen is unmistakable — secondary and tertiary actions stay outlined/ghost. Supporting copy sized below 13px has been bumped up for phone readability.

Frames are shown at mobile width (328px) with a hairline device edge.
